**# Bank Customer Churn Analysis Dashboard

## Project Overview
This project analyses customer churn behaviour in a banking dataset using SQL and Tableau.

## Tools Used
- MySQL
- Tableau
- GitHub

## Key Insights
- Overall churn rate: 20.37%
- Germany recorded the highest churn rate (32.44%)
- Customers above 50 years showed the highest churn risk
- Female customers churned more frequently than male customers
- Inactive members were nearly twice as likely to churn
- Customers with 3–4 products exhibited extremely high churn rates

## Recommendations
- Focus retention campaigns on Germany
- Improve engagement of inactive customers
- Provide loyalty benefits for customers above 50
- Develop targeted retention programs for female customers
- Monitor customers holding multiple products
